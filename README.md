# Лабораторная работа №2

## Предметная область

Служба доставки еды

## Описание

В рамках лабораторной работы реализовано серверное приложение на ASP.NET Core (.NET 10), предоставляющее REST API для управления данными службы доставки еды

Приложение поддерживает CRUD-операции для основных сущностей предметной области и предоставляет результаты аналитических запросов

Данные хранятся в оперативной памяти и заполняются при помощи `DataSeeder`

## Сущности

- `Client` — клиент службы доставки
- `Restaurant` — ресторан
- `DishCategory` — категория блюд
- `Dish` — блюдо ресторана
- `Order` — заказ клиента

## REST API

Для каждой сущности реализованы операции получения списка, получения по идентификатору, создания, изменения и удаления

| Сущность | Маршрут |
|---|---|
| Рестораны | `/api/restaurants` |
| Клиенты | `/api/clients` |
| Категории блюд | `/api/categories` |
| Блюда | `/api/dishes` |
| Заказы | `/api/orders` |

Поддерживаются HTTP-методы `GET`, `POST`, `PUT`, `DELETE`

При выполнении запросов предусмотрена проверка входных данных и возврат соответствующих HTTP-статусов

## Аналитические запросы

Реализованы следующие аналитические маршруты:

1. `GET /api/analytics/top-restaurants` — получение пяти ресторанов с наибольшим количеством заказов
2. `GET /api/analytics/fastest-orders` — получение заказов с минимальным временем доставки
3. `GET /api/analytics/restaurant-clients/{restaurantId}` — получение уникальных клиентов указанного ресторана
4. `GET /api/analytics/category-statistics?startDate=...&endDate=...` — получение статистики заказанных блюд по категориям за выбранный период
5. `GET /api/analytics/top-clients` — получение клиента с максимальной общей суммой заказов

Для представления аналитических результатов используются типизированные DTO

## Структура проекта

- `EnterpriseDevelopment.Domain` — сущности предметной области и тестовые данные
- `EnterpriseDevelopment.Application` — интерфейсы, сервисы и DTO
- `EnterpriseDevelopment.Api` — HTTP-обработчики REST API
- `EnterpriseDevelopment.Application.Tests` — модульные тесты сервисов

Взаимодействие между HTTP-обработчиками и сервисами реализовано с помощью Dependency Injection

## Тестирование

Модульные тесты реализованы с использованием xUnit
