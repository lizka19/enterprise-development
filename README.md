
# Лабораторная работа №1

## Предметная область

Служба доставки еды.

## Описание

В рамках лабораторной работы реализована объектная модель предметной области и unit-тесты для проверки LINQ-запросов.

Данные хранятся в памяти в коллекциях и заполняются при помощи DataSeeder.

## Сущности

- Client — клиент службы доставки;
- Restaurant — ресторан;
- DishCategory — категория блюда;
- Dish — блюдо ресторана;
- Order — заказ клиента.

## Тестовые данные

В DataSeeder содержатся:

- 10 клиентов;
- 10 ресторанов;
- 10 категорий блюд;
- 12 блюд;
- 12 заказов.

## LINQ-запросы

Реализованы следующие запросы:

1. Получение пяти ресторанов с максимальным количеством заказов.
2. Получение заказов с минимальным временем доставки.
3. Получение клиентов выбранного ресторана с сортировкой по ФИО.
4. Получение количества заказов, средней суммы заказа и общей суммы заказов.
5. Получение клиента с максимальной общей суммой заказов.

## Тестирование

Для проверки запросов используются unit-тесты на xUnit.

Тестовые данные передаются через IClassFixture<FoodDeliveryFixture>.

## GitHub Actions

В репозитории настроен CI:

- восстановление зависимостей;
- сборка проекта;
- запуск unit-тестов.
